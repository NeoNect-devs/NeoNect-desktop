# Desktop Client

This directory contains the desktop client for the Avila chat application. It's built using C++ and Qt.

## Technologies

*   C++
*   Qt
*   CMake

## Setup

1.  Navigate to the `desktop-client` directory: `cd desktop-client`
2.  Create a build directory: `mkdir build`
3.  Navigate to the build directory: `cd build`
4.  Configure the project: `cmake ..`
5.  Build the project: `cmake --build .`

## Run

1.  Navigate to the build directory: `cd build`
2.  Run the client: `./AvilaDesktopClient` (or the appropriate executable name)

## Structure

*   `src/`: Contains the client's source code.
*   `CMakeLists.txt`: CMake configuration file.
